1. Beide VMs in den VM Settings auf Bridged Mode
   umstellen.

2. Die IP-Adressen der beiden VMs herausfinden:
   Kali: ip a

3. Metasploitable: ifconfig eth0

4. Mit route -n das Default Gateway herausfinden.
   Von Kali Metasploitable anpingen:
   ping 192.168.3.XX
   Von Metasploitable Kali anpingen:
   ping 192.168.3.XX

5. Vom Windows-PC beide VMs anpingen.

6. Von Kali auch den Windows-PC anpingen.

7. Von Kali ein anderes Kali-System auf einem anderen 
   Rechner anpingen.

8. Danach habe ich beide VMs wieder auf NAT umgestellt und die Ping-Versuche wiederholt.
