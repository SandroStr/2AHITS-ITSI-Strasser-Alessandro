## Durchführung

### 1. Bridged Mode einstellen

Zuerst habe ich bei beiden VMs (Kali und Metasploitable) in den VM Settings
den Netzwerkadapter auf Bridged Mode umgestellt.

### 2. IP-Adresse von Kali

Dann habe ich die IP-Adresse von Kali herausgefunden:

```
ip a
```

### 3. IP-Adresse von Metasploitable

Bei Metasploitable habe ich die IP-Adresse so herausgefunden:

```
ifconfig eth0
```

### 4. Default Gateway

Mit diesem Befehl habe ich mir das Default Gateway angeschaut:

```
route -n
```

### 5. VMs gegenseitig anpingen

Danach habe ich getestet, ob sich die beiden VMs gegenseitig erreichen.

Von Kali aus Metasploitable anpingen:

```
ping 192.168.3.XX
```

Von Metasploitable aus Kali anpingen:

```
ping 192.168.3.XX
```

### 6. Vom Windows-PC anpingen

Vom Windows-PC aus habe ich beide VMs angepingt.

### 7. Von Kali den Windows-PC anpingen

Von Kali aus habe ich auch den Windows-PC angepingt.

### 8. Anderes Kali anpingen

Zum Schluss habe ich von meinem Kali noch ein anderes Kali-System auf einem
anderen Rechner angepingt.

### 9. Zurück auf NAT

Danach habe ich beide VMs wieder auf NAT umgestellt und die Pings nochmal gemacht.

## Problem

Bei manchen Pings ist hinter der Antwort (DUP!) gestanden. Das heißt, dass auf
ein Ping-Paket zwei Antworten zurückgekommen sind. Ich glaube, das liegt am
Bridged Mode im Schulnetz, weil die Pakete dort doppelt ankommen können.
