```sh
$ touch sum.cpp
$ nano sum.cpp
```

---

## 2. C++ Programm schreiben

### Inhalt von sum.cpp

```cpp
#include <stdio.h>

int main() {
    int n;
    int sum = 0;

    if (scanf("%d", &n) != 1) {
        return 1;
    }

    for (int i = 0; i < n; i++) {
        int num;
        if (scanf("%d", &num) != 1) {
            return 1;
        }
        sum += num;
    }

    printf("%d\n", sum);
    return 0;
}
```

---

## 3. Kompilieren

```sh
$ g++ -o sum sum.cpp
$ ls
sum  sum.cpp
```

* Ergebnis: Programm `sum` erstellt
