## Befehle und Erklärungen

```sh
$ cat
```
#### Zeigt den Inhalt einer Datei an oder wartet, bis man Text eingibt. (Mit Strg + C kommt man wieder raus.)


```sh
$ cat >text.txt
```
#### Erstellt eine neue Datei text.txt und schreibt das, was man eingibt, hinein. (Mit Strg + C beenden.)


```sh
$ echo Hallo Welt
```
#### Gibt einfach den Text Hallo Welt im Terminal aus.

```sh
$ echo Hallo Welt >hallo.txt
```
#### Schreibt Hallo Welt in die Datei hallo.txt
```sh
$ #
```
#### Wird für Kommentare benutzt. Alles, was nach dem # steht, wird nicht ausgeführt.

# Eingabe und Ausgabe in der Shell: stdin und stdout

In der Shell (z. B. Bash) sind **stdin** und **stdout** zentrale Konzepte für **Ein- und Ausgabe von Programmen**.

## 1. stdin (Standard Input)
- **Definition:** `stdin` steht für **Standard Input**.  
- **Funktion:** Ein Programm liest Daten von `stdin`, z. B. von der **Tastatur** oder aus einer **Datei**.
- **Wichtig:**  
  - `stdin` ist standardmäßig die Tastatur.  
  - Kann durch **Umleitung** von Dateien oder Pipelines ersetzt werden.

---

## 2. stdout (Standard Output)
- **Definition:** `stdout` steht für **Standard Output**.  
- **Funktion:** Ein Programm schreibt seine **Ausgabe an stdout**, standardmäßig auf den Bildschirm.
- **Wichtig:**  
  - `stdout` kann **umgeleitet** oder **an andere Programme weitergeleitet** werden.  
  - Mit **stdin** und **stdout** kann die Shell Sachen einfach von einem Programm zum anderen schieben..

---

## 3. Zusammenfassung

| Begriff  | Zweck                                 | Shell-Beispiel                        |
|----------|--------------------------------------|--------------------------------------|
| **stdin** | Eingabestrom ins Programm            | z. B. Tastatureingabe oder Datei    |
| **stdout** | Ausgabestrom aus dem Programm       | z. B. Bildschirmausgabe oder Datei  |

**Merke:**  
- **stdin = Eingang** (Input)  
- **stdout = Ausgang** (Output)  
- Beide können **umgeleitet** oder **verbunden** werden, z. B. in **Pipelines**.

## Übung (Kopie mit cat)
### Erstelle mit Hilfe von “cat” eine Kopie der Datei test.txt in der neuen Datei test2.txt. test2.txt soll den gleichen Inhalt enthalten wie test.txt. Prüfe ob test2.txt wirklich den gewünschten Inhalt hat.


**Lösung**  
```sh
$ cat test.txt > test2.txt
$ cat test2.txt
```

## Übung (dirlist in File)

**Lösung**  

## Übung (Textdatei erstellen)
### Mit Hilfe von mehreren echo Befehlen können einfache Textdateien erstellt werden.  
Erzeuge nur unter Verwendung von echo Befehlen die Datei made_by_echoing.txt mit Inhalt:

**Lösung**  
```sh
$ echo "=====================" > made_by_echoing.txt
$ echo "=    HTL BRAUNAU    =" >> made_by_echoing.txt
$ echo "=====================" >> made_by_echoing.txt
$ echo "= 2AHITS Gruppe 2   =" >> made_by_echoing.txt
$ echo "= 0 Schülerinnen    =" >> made_by_echoing.txt
$ echo "= 13 Schüler        =" >> made_by_echoing.txt
$ echo "=====================" >> made_by_echoing.txt
$ cat made_by_echoing.txt
```
