## Übung (Binary File Patching I)
Die Änderungen lassen sich auch permanent im Binärfile des Programms durchführen. Dazu analysiert man mit objdump -d pwcheck die Programmdatei um herauszufinden auf welchem Offset sich die zu manipulierenden Daten befinden.

### Schritt 1
```sh
$ objdump -d pwcheck
```
zerlegt das programm in einen lesbaren Assembler code

So sieht die relevante Stelle aus:
```sh
    11c5:       83 f8 00                cmp    $0x0,%eax
    11c8:       0f 84 95 00 00 00       je     1263 <main+0xf3>
```
---
### Schritt 2
```sh
$ hexedit pwcheck
```
öffnet hexeditor

---
### Schritt 3
1. Drücke strg + g
2. 11c8 eingeben
3. Ändere 0f 84 95 00 00 00 zu 90 90 90 90 90 90
4. Drücke strg + x zum speichern

---
### Schritt 4
```sh
$ ./pwcheck
```
testen ob es geht

So sollte es aussehen:
```sh
~/workspace$ ./pwcheck
Enter password: hallo
Correct
Password was: G7pL9xQ2mR4tZcH
```

## Übung (Binary File Patching II)
Patche auch die Änderung von Addition auf Subtraktion ins Programm-Binary.

---
### Schritt 1
```sh
$ objdump -d pwcheck
```
In der Ausgabe nach dem ADD Befehl suchen:
```sh
    1249:       03 44 24 08             add    0x8(%rsp),%eax
```
Der Offset ist 1249, der opcode 03 muss auf 2b geändert werden.

---
### Schritt 2
```sh
$ hexedit pwcheck
```
öffnet den hexeditor

---
### Schritt 3
1. Drücke strg + g
2. 1249 eingeben
3. Ändere 03 zu 2b
4. Drücke strg + x zum speichern

---
### Schritt 4
```sh
$ ./pwcheck
```
testen – vorher mit add, nachher mit sub:
```sh
~/workspace$ ./pwcheck
Enter password: hallo
Correct
Password was: G7pL9xQ2mR4tZcH
Enter first number: 10
Enter second number: 3
Result=7
```
Statt Result=13 (addition) kommt jetzt Result=7 (subtraktion)

## Übung (jne)
Statt nop patchen wir den je Befehl direkt auf jne um. jne macht genau das Gegenteil von je, das Ergebnis ist dasselbe wie beim nop-patching.

---
### Schritt 1 – Zuerst im Debugger testen
```sh
$ gdb pwcheck
```
öffnet den GNU Debugger

---
### Schritt 2
```sh
(gdb) break *0x11c8
```
setzt einen Haltepunkt an dieser Adresse

---
### Schritt 3
```sh
(gdb) run
```
startet das Programm, stoppt am Haltepunkt

---
### Schritt 4
```sh
(gdb)  *(char*)0x11c9 = 0x85
```
ändert nur das zweite Byte von 84 je auf 85 jne

---
### Schritt 5
```sh
(gdb) continue
```
```sh
Enter password: hallo
Correct
Password was: G7pL9xQ2mR4tZcH
```
funktioniert – jetzt fix ins Binary schreiben

---
### Schritt 6
```sh
$ hexedit pwcheck
```
1. Drücke strg + g
2. 11c9 eingeben (nur das zweite Byte!)
3. Ändere 84 zu 85
4. Drücke strg + x zum speichern

---
### Schritt 7
```sh
$ ./pwcheck
```
